# Calculadora de Honorarios Arquitectónicos

Esta es una aplicación web que calcula honorarios arquitectónicos basados en el área, categoría y etapa del proyecto, así como la experiencia del arquitecto.

## Cómo usar
1. Suba estos archivos a una plataforma de alojamiento como Render.
2. Asegúrese de que las dependencias de `requirements.txt` se instalen.
3. Configure el comando de inicio con:
   ```bash
   python app.py
